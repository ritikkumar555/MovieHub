# 🎬 MovieHub

A responsive movie-search web application built with **HTML, CSS, and JavaScript** that allows users to search for movies and explore movie information through a movie API.

🔗 **Live Demo:** https://movie-hub-ritik-kumar.vercel.app/

## ✨ Features

* 🔍 Search for movies by title
* 🎞️ Fetches movie data dynamically using an API
* 📱 Responsive and user-friendly interface
* ⚡ Dynamic search results without page reloads
* 🖼️ Displays movie posters and relevant movie information
* ⏳ Loading state while fetching data
* ❌ Handles empty search results gracefully
* 🌐 Deployed with Vercel

## 🛠️ Tech Stack

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic, API requests, and DOM manipulation
* **Movie API** — Fetching movie data
* **Vercel** — Deployment

## ⚙️ How It Works

1. The user enters a movie title in the search field.
2. JavaScript sends a request to the movie API.
3. The application processes the API response.
4. Movie information is dynamically rendered on the page.
5. Users can search for another movie without refreshing the page.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/moviehub.git
```

### 2. Navigate to the project

```bash
cd moviehub
```

### 3. Open the project

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

> If your API requires a key, add your API key according to the configuration used in the project.
